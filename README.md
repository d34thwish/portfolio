# Ades Portfolio

This is my personal portfolio showcasing selected projects that demonstrate my learning and development experience.

## Purpose

The portfolio site provides an overview of my projects, their problem-solving context, and outcomes. It’s intended for anyone interested in my work as a developer.

## Tech Stack

* **HTML5** – structure
* **CSS3** – styling and responsive design
* **GitHub Pages / Netlify** – deployment (static site hosting)

## Setup Instructions

1. Clone the repository:

```bash
git clone https://github.com/d34thwish/portfolio.git
```

2. Open `index.html` in your browser to view the site locally.
3. (Optional) Deploy using GitHub Pages or Netlify for live hosting.
